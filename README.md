

# Online FIR Registration System

## Overview
The **Online FIR Registration System** is a Java-based software application designed to help police officers register First Information Reports (FIRs) online. The application streamlines the FIR registration process and simplifies data management for law enforcement. It enables police inspectors to easily update and manage information about criminals and their cases.

## Features
- **Online FIR Registration:** Allows police officers to register FIRs online for quicker and more efficient handling.
- **Data Management:** Facilitates easy management of FIRs and criminal records, allowing inspectors to update and track case details.
- **User-friendly Interface:** Built using Java Swing to provide an intuitive and responsive interface for users.
- **Database Integration:** Uses MySQL to store and manage FIR data securely and efficiently, with Hibernate ORM for seamless database operations.

## Tech Stack
- **Java Swing:** Used to build the user interface.
- **Hibernate:** ORM tool used for database interaction and management.
- **MySQL:** Relational database management system used to store FIR and criminal data.
